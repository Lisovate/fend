# @fendsh/cli-darwin-arm64

Native `fend` binary for macOS Apple Silicon. Installed automatically as an optional dependency of [`@fendsh/cli`](https://www.npmjs.com/package/@fendsh/cli) — you should not depend on this package directly.

The source tree intentionally tracks only this package metadata. The native
binary under `bin/` is staged by `scripts/build-binary.sh` during release
packaging and is not committed to git.

See https://github.com/Lisovate/fend for the source and docs.
